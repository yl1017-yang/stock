# 💹 주식 테마 분석기 (Stock Theme Analyzer) - 개발 가이드

이 문서는 프로젝트의 구조, 개발 원칙 및 협업을 위한 가이드라인을 담고 있습니다. AI 어시스턴트나 새로운 개발자가 프로젝트에 참여할 때 이 문서를 가장 먼저 참고하십시오.

---

## 1. 프로젝트 핵심 개념

본 프로젝트는 **"오늘의 핫 테마 종목 분석 및 수익성 검증 자동화"**를 목표로 합니다.

- **Data First**: 모든 데이터는 파이썬이 객관적으로 수집 및 분석합니다.
- **Premium UI**: 분석된 결과는 사용자에게 '프리미엄' 감성의 현대적인 대시보드로 제공됩니다.
- **Separation of Concerns**: 데이터 분석 엔진(Python)과 UI 렌더링 엔진(JS)은 완전히 독립되어 동작합니다.

---

## 2. 시스템 아키텍처 및 역할

프로젝트는 **데이터 엔진**과 **UI 엔진**으로 이원화되어 있습니다.

### 2.1 🐍 데이터 분석 엔진 (파이썬 / `main.py`)

- **수집 파이프라인 (2-Track)**:
  1. **단기 급등 테마주 추적**: 새 네이버 증권 JSON API의 테마·구성종목·종목 상세 데이터와 토스증권 일봉을 결합해 수집합니다.
  2. **[AUTO] 국내 성장 저평가주 발굴**:
     - **GARP형 탐색**: 미래 성장 테마(AI, 로봇, 반도체, 에너지, K뷰티/화장품, 소비재, 엔터/게임 등)는 가산점으로 우선하되, KRX 전체에서도 가격이 합리적이고 시장 관심이 회복되는 종목을 함께 찾습니다.
     - **과도한 소외주 제외**: 단순히 많이 빠진 종목이 아니라, 52주 고점 대비 하락폭이 과도하지 않고 6개월 장기 소외 여부, 최근 3개월 흐름, 1개월 진입 타이밍, 거래대금, 20일/60일선 회복이 확인되는 종목을 선별합니다.
     - **성장 저평가 점수화**: 핫한 테마 여부, 밸류에이션, 목표가대비 괴리율, 수급 회복, 이평선 회복, 유동성을 점수화하고 과도한 하락/약한 모멘텀은 감점합니다.
  3. **[AUTO] 미국 성장 저평가주 발굴**:
     - **GARP 필터**: PER/PBR이 과도하지 않으면서 Forward PE 개선, 매출 성장률, EPS 성장률 중 하나 이상이 확인되는 종목을 우선합니다.
     - **관심 회복 조건**: 3개월 수익률, 1개월 수익률, 20일/50일선 회복, 거래량 회복, 주도 섹터 여부를 반영하여 너무 소외된 종목을 제외합니다.
     - **러셀 1000 테마 탐색**: S&P 500뿐만 아니라 **Russell 1000(미국 상위 1,000개 기업)**까지 범위를 넓혀 유망한 중견 성장주를 발굴합니다.
  4. **[AUTO] 미국 핫 테마 발굴**:
     - AI/데이터센터, 반도체, 전력 인프라, 방산/우주항공, 바이오, 사이버보안 등 주요 미국 성장 테마 바스켓을 추적합니다.
     - 최근 1개월 평균 수익률이 강한 테마를 우선 표시하고, 각 테마 안에서 20일선 위에 있는 강한 종목을 선별합니다.
- **투자 지표/수익성 검증**:
  - **프리미엄 지표 산출 (Investing.com 스타일)**:
    - **목표가대비 괴리율(Upside)**: 증권사 목표주가(컨센서스)와 현재가를 비교하여 목표가와 현재가의 괴리율 산출.
    - **적정가치(Fair Value)**: 전문가들이 판단한 기업의 평균 목표가 표시.
    - **투자 등급**: 재무건전성(부채비율 등), 수익성(ROE 등), 성장성(영업이익률 등)을 분석하여 [최고/우수/보통/주의] 4단계 등급 부여.
    - **투자의견**: 애널리스트들의 종합적인 매수/매도 의견 수집.
  - **국내 적정가 수집 최적화**: 네이버 금융의 우측 사이드바(사이드 컨센서스) 및 하단 보고서를 교차 검증하여 중대형주의 목표주가 수집 성공률을 극대화함.
  - **국내 현재가 기준**: 국내 테마와 국내 저평가의 화면 표시 현재가, PER/PBR, 배당률 및 컨센서스는 새 네이버 증권 JSON API를 사용합니다. 1개월/3개월/6개월 수익률, 이동평균, RSI, 거래량 등 추세 판단은 KRX OHLCV를 우선 사용하고 KRX 인증 정보가 없거나 조회가 실패하면 토스증권 일봉 API를 사용합니다.
  - **RSI 과열/고점주의 표시**: 14일 RSI, 단기 급등, 목표가대비 괴리율, 52주 고점 근접, 20일선 괴리율을 함께 확인해 `RSI과열`, `과열강함`, `고점주의` 같은 주의 플래그를 붙입니다. RSI만으로 고점이라고 단정하지 않습니다.
  - Open DART API 및 네이버 재무제표 스크래핑을 혼용하여 지표 수집(Fallback 로직 내장).
- **저평가 선별 기준**: 국내/미국 성장 저평가의 세부 조건과 점수화 방식은 `2.2 저평가 선별 기준`을 따릅니다.
- **성장 테마 자동 탐지 원칙**: 성장 키워드는 강제 조건이 아니라 안전장치입니다. 네이버 테마 상대강도, 선택적 뉴스/검색 보조 점수, 최종 검증 조건을 함께 사용하며 검증을 통과한 테마를 `growth_focus`에 포함합니다. 국내 저평가에서는 이 테마를 필수 조건이 아닌 가산점으로 사용합니다.
- **출력**: 분석 결과를 `data.json` 파일로 생성.
- **알림**: 분석 완료 시 카카오톡 알림 메시지 전송 (`kakao_api.py`). 기본 알림은 **국내 테마 TOP10**, **미국 테마 TOP10**, **국내 저평가 TOP10**, **미국 저평가 TOP10**을 짧은 메시지로 나눠 발송합니다.

### 2.2 저평가 선별 기준

저평가 탭은 단순히 가격이 많이 빠진 종목을 찾는 기능이 아닙니다. 목표는 **성장 가능성이 있거나 실적/수급 회복 조짐이 있는 종목 중 가격이 합리적이고, 시장 관심이 다시 붙기 시작한 종목**을 찾는 것입니다.

#### 성장 테마 자동 탐지

성장 테마는 완전 하드코딩하지 않습니다. 다만 자동 탐지의 노이즈를 줄이기 위해 키워드 기반 안전장치와 시장 데이터 기반 검증을 함께 사용합니다.

1. **기본 키워드 기반 유지**: AI, 로봇, 반도체, 전력, 데이터센터, 바이오, 우주, 방산, K뷰티/화장품, 소비재, 엔터/게임 등 알려진 성장 키워드는 가산점으로만 사용합니다.
2. **자동 후보 테마 점수 추가**: 네이버 테마 상승률, 전체 테마 내 상대 순위, 강한 시장 관심도를 점수화합니다. 키워드에 없는 새 테마도 시장 강도가 충분하면 후보가 될 수 있습니다.
3. **뉴스/검색 보조 점수 사용**: 네이버 뉴스 검색 API와 네이버 데이터랩 검색어 트렌드 API는 선택적 보조 점수입니다. 단독으로 테마를 채택하지 않고, 시장 점수와 함께 검증될 때만 반영합니다.
4. **검증 통과 테마만 포함**: 구경제 테마이면서 상승률이 약한 경우는 제외하고, 키워드 점수, 자동 시장 점수, 보조 점수 중 최소 하나가 충분한 테마만 `growth_focus`에 포함합니다.

현재 구현에서는 네이버 API 키가 있으면 뉴스/검색 보조 점수를 자동 반영합니다. 끄고 싶으면 `.env`에 `ENABLE_THEME_CONTEXT_SCORE=false`, `ENABLE_NAVER_NEWS_SCORE=false`, `ENABLE_NAVER_DATALAB_SCORE=false`를 설정합니다.

#### 핵심 방향

- **저평가**: PER, PBR, 목표가대비 괴리율로 가격 부담을 확인합니다.
- **성장성**: 성장 테마, Forward PE 개선, 매출 성장률, EPS 성장률을 확인합니다.
- **관심 회복**: 6개월 흐름으로 장기 소외 여부를 확인하고, 3개월 흐름을 기본 추세로 보며, 1개월 수익률은 진입 타이밍 확인용으로 사용합니다. 이평선 회복과 거래량/거래대금 회복도 함께 확인합니다.
- **소외주 제외**: 너무 오래 방치되었거나 52주 고점 대비 과도하게 하락한 종목은 제외합니다.

#### 국내 성장 저평가

국내 저평가는 두 경로로 후보를 찾습니다.

1. **성장 테마 기반 후보**: 검증된 성장 테마 안의 종목을 먼저 평가하고, 테마 관심도와 시장 강도를 가산점으로 반영합니다.
2. **숨은 저평가 후보**: 핫한 테마에 포함되지 않아도 KRX 전체에서 밸류에이션, 목표가대비 괴리율, 거래대금, 6개월 장기 소외 여부, 3개월 흐름, 이평선 회복이 맞는 종목을 별도로 평가합니다.

공통 조건은 아래와 같습니다.

1. PER 35 이하, PBR 4 이하일 것
2. 목표가대비 괴리율 8% 이상일 것 (단, 목표가 컨센서스가 없더라도 재무 수익성 등급이 '최고' 또는 '우수'이면 예외적으로 통과 가능)
3. 52주 고점 대비 하락폭이 3%~50% 구간일 것
4. 최근 6개월 수익률이 -40% 이하이면 장기 소외 위험으로 볼 것
5. 최근 3개월 수익률이 -20%보다 양호할 것
6. 최근 1개월 수익률이 -12%보다 양호할 것
7. 현재가가 20일선 또는 60일선 위로 회복했을 것
8. 숨은 저평가 후보는 최근 20거래일 평균 거래량이 60거래일 평균의 70% 이상일 것 (성장 테마 후보는 점수에만 반영)
9. 최근 5거래일 평균 거래량이 20거래일 평균 대비 크게 죽지 않았을 것
10. 성장 테마 후보는 최소 거래대금 10억 원 이상, 숨은 저평가 후보는 최소 거래대금 20억 원 이상일 것

성장 테마 후보는 6개월 수익률 -40% 이하와 중기 거래량 회복을 감점/가산점으로만 반영합니다. 숨은 저평가 후보는 테마 가산점이 없으므로 6개월 수익률 -40% 이하와 중기 거래량 부진을 제외 조건으로 적용하고, 최소 7점과 거래대금 기준을 요구합니다.

감점 조건은 다음과 같습니다.

- 52주 고점 대비 50% 이상 하락
- 최근 6개월 수익률 -40% 이하
- 최근 3개월 수익률 -15% 이하
- 최근 1개월 수익률 -10% 이하
- 목표가대비 괴리율이 80%를 넘는 과도한 목표가 괴리

#### 미국 성장 저평가

미국 저평가는 GARP 관점으로 아래 조건을 점수화합니다.

1. PER 45 이하, PBR 12 이하일 것
2. 시가총액 20억 달러 이상일 것
3. 평균 거래량 30만 주 이상일 것
4. Forward PE가 Trailing PE보다 낮거나, 매출 성장률 또는 EPS 성장률이 양수일 것
5. 목표가대비 괴리율 8% 이상일 것 (단, 목표가 컨센서스가 없더라도 재무 수익성 등급이 '최고' 또는 '우수'이면 예외적으로 통과 가능)
6. 52주 고점 대비 하락폭이 3%~50% 구간일 것
7. 최근 3개월 수익률이 -20%보다 양호할 것
8. 최근 1개월 수익률이 -12%보다 양호할 것
9. 현재가가 20일선 또는 50일선 위로 회복했을 것
10. 최근 20거래일 평균 거래량이 3개월 평균의 70% 이상이거나, 최근 5거래일 거래량이 20거래일 평균 대비 유지될 것
11. 주도 섹터에 포함되면 가산점을 줄 것
12. Alpha Vantage 뉴스/심리 점수는 최대 +2점까지만 보조 반영할 것

감점 조건은 다음과 같습니다.

- 52주 고점 대비 50% 이상 하락
- 최근 3개월 수익률 -15% 이하
- 최근 1개월 수익률 -10% 이하
- 목표가대비 괴리율이 90%를 넘는 과도한 목표가 괴리
- Alpha Vantage 뉴스 심리가 명확히 부정적인 경우

#### 점수화 개념

```text
성장저평가점수 =
  밸류에이션점수
+ 성장성점수
+ 목표가대비괴리율점수
+ 최근수급점수
+ 이평선회복점수
+ 유동성점수
- 과도한소외패널티
- 과열/과도한목표가괴리패널티
```

현재 구현은 `main.py`의 `find_undervalued_turnaround_stocks()`, `get_us_hot_theme_stocks()`, `scan_us_tickers()`에서 이 기준을 사용합니다.

### 2.3 🐑 양 종목 관리 및 분석 (개인 포트폴리오)

사용자가 개별적으로 매수했거나 관심이 있는 종목들을 수동 등록하고, 토스증권 실제 보유종목을 자동으로 불러와 대시보드에서 일괄 분석 및 관리할 수 있는 기능입니다.

- **토스증권 계좌 자동 연동 (`toss_api.py`)**:
  - `.env`에 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`이 있으면 `main.py` 실행 시 자동으로 활성화됩니다.
  - OAuth 2.0 Client Credentials 방식으로 액세스 토큰을 발급받은 후 계좌 목록과 보유종목을 조회합니다.
  - 여러 계좌가 있으면 `TOSS_ACCOUNT_SEQ`와 일치하는 계좌를 사용하고, 설정하지 않았거나 일치하는 계좌가 없으면 첫 번째 계좌를 사용합니다.
  - 종목명, 심볼, 통화, 보유수량, 평균 매수가, 현재가, 평가금액, 평가손익, 누적 수익률 및 당일 손익을 가져옵니다.
  - 토스 API의 수익률은 비율 값이므로 화면 출력 시 100을 곱해 백분율로 변환합니다.
  - 계좌번호, `client_secret`, 액세스 토큰은 `data.json`에 저장하지 않습니다.
  - 토스 연동 실패 시 오류를 로그로 남기고 나머지 시장 분석 파이프라인은 계속 실행합니다.

- **UI 연동**:
  - 대시보드 우측 하단에 **[양 종목]** 필터 탭이 추가됩니다.
  - 토스 보유종목은 **토스 평균단가**, **보유수량**, **평가금액**, **평가손익**, **누적 수익률**을 표시합니다.

| `TOSS_ACCOUNT_SEQ`           | 사용할 토스증권 계좌 식별 순번           | 선택, 미설정 시 첫 계좌  |

### 4.1 토스증권 Open API 설정

1. [토스증권 Open API 페이지](https://p.tossinvest.com/ko/open-api) 또는 토스증권 WTS의 **설정 > Open API**에서 이용 신청과 키 발급을 완료합니다.
2. API를 실행할 PC 또는 서버의 공인 IP를 **허용 IP 관리**에 등록합니다. 등록되지 않은 IP의 요청은 `403`으로 차단됩니다.
3. 프로젝트 루트의 `.env`에 아래 값을 추가합니다.

   ```env
   TOSS_CLIENT_ID=발급받은_client_id
   TOSS_CLIENT_SECRET=발급받은_client_secret
   # 계좌가 여러 개일 때만 선택적으로 설정
   TOSS_ACCOUNT_SEQ=1
   ```

4. `.env`는 `.gitignore`에 포함되어 있어야 하며, 비밀키나 액세스 토큰을 문서·소스·로그·`data.json`에 기록하지 않습니다.

API 호출 순서는 `POST /oauth2/token` → `GET /api/v1/accounts` → `GET /api/v1/holdings`입니다. 계좌 및 보유종목 요청에는 `Authorization: Bearer ...` 헤더를 사용하며, 보유종목 요청에는 `X-Tossinvest-Account` 헤더를 추가합니다.

자주 발생하는 오류는 다음과 같습니다.

- `401`: `client_id` 또는 `client_secret`이 잘못되었거나 폐기된 경우
- `403`: 현재 실행 환경의 공인 IP가 허용 IP에 등록되지 않은 경우
- `429`: API 호출 제한을 초과한 경우
- 계좌가 여러 개인데 다른 계좌가 표시됨: `TOSS_ACCOUNT_SEQ`를 원하는 계좌의 `accountSeq`로 지정

### 💬 카카오 알림 기준

`main.py`는 `data.json` 저장 후 아래 기준으로 카카오 알림을 발송합니다.

- **국내 테마 TOP10**: `domestic_theme` 중 1개월 수익률 상위 10개
- **미국 테마 TOP10**: `us_theme` 중 1개월 수익률 상위 10개
- **국내 저평가 TOP10**: `domestic_value` 중 1개월 수익률 상위 10개
- **미국 저평가 TOP10**: `us_sp`, `us_ndq`, `us_rsl`을 합친 뒤 종목코드 중복을 제거하고 1개월 수익률 상위 10개

카카오 기본 텍스트 메시지는 길이 제한이 있으므로 한 메시지에 모두 넣지 않고, 약 180자 기준으로 자동 분할해 여러 번 발송합니다.

### 🛠️ 수정 범위 판단 기준

- **값이 없거나 틀린 경우**: `main.py`의 수집/계산 로직과 `data.json`의 실제 필드를 확인합니다.
- **화면에 표시되지 않는 경우**: `script.js`의 렌더링 로직과 데이터 키 이름이 일치하는지 확인합니다.
- **필터 탭이 이상한 경우**: `script.js`의 `filterData()`와 `category` 값을 확인합니다.
- **카드 개수, 너비, 반응형이 이상한 경우**: `style.css`의 `.dashboard-grid`, `.theme-card`, `@media` 규칙을 확인합니다.
- **데이터 스키마가 바뀐 경우**: `main.py`, `data.json`, `script.js`, `docs/GUIDE.md`를 함께 확인합니다.

### ⚠️ 외부 수집 실패 주의사항

`main.py`는 네이버 금융, KRX, Yahoo Finance, Open DART 등 외부 데이터에 의존합니다. 외부 사이트 응답, 차단, 인코딩, 인증 상태에 따라 실행 결과가 달라질 수 있습니다.

- `python main.py` 실행 후 데이터 수가 비정상적으로 줄면 즉시 정상으로 간주하지 말고 원인을 확인합니다.
- KRX 투자지표 수집 실패 시 네이버 상세 데이터 fallback이 사용될 수 있습니다.
- `KRX_ID`, `KRX_PW`, `DART_API_KEY`가 없으면 일부 검증 또는 수집이 제한될 수 있습니다.
- 재생성된 `data.json`이 기존보다 크게 줄었거나 특정 카테고리가 사라졌다면, 배포 또는 커밋 전에 `git diff -- data.json`으로 변경 폭을 확인합니다.
- 외부 수집 실패가 의심되면 코드 변경과 데이터 변경을 분리해서 판단합니다.

## 6. 로컬 실행 및 배포

### 6.1 사전 준비 (Python 설치)

데이터 엔진(`main.py`)을 실행하려면 파이썬 설치가 필요합니다. (프론트엔드 UI 디자인 및 기능 수정만 할 경우에는 설치하지 않아도 됩니다.)

1. [Python 공식 다운로드](https://www.python.org/downloads/)에서 **Python 3.11 또는 3.12** 버전을 다운로드합니다.
2. 설치 마법사 첫 화면 하단의 **`Add python.exe to PATH`** 체크박스를 반드시 체크한 후 설치하십시오. (체크하지 않으면 명령어가 동작하지 않습니다.)
3. python --version 확인

### 6.2 로컬 실행

1. `pip install -r requirements.txt` 또는 `python -m pip install -r requirements.txt`
2. 토스 계좌 연동을 사용할 경우 `.env`에 API 키를 저장하고 현재 PC의 공인 IP를 토스증권 허용 IP로 등록
3. `python main.py` (`data.json` 데이터가 생성되며 토스 API 키가 있으면 실제 보유종목도 포함됨) 
4. `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속
5. 대시보드의 **양 종목** 탭에서 토스 평균단가, 수량, 평가금액 및 평가손익 확인

.\.venv\Scripts\python.exe main.py (최신데이터 완전 교체)

### 6.3 배포

- GitHub Actions가 주기적으로 `main.py`를 자동 실행하여 최신 데이터가 포함된 `data.json`과 함께 GitHub Pages로 정적 배포를 수행합니다.
